# FM26MoneyBallReleases

FM 26 Money Ball App

Uses https://www.fmscout.com/a-fm26-player-csv-export.html mod to export player data

Use custom database views supplied and export data

Run the App

Can predict

- Keepers
- CentreBacks
- Wing and Full Backs
- Def Mids
- Midfielders (M(LCR) AM)
- Wingers
- Strikers


XGBoost models are used to predict valuations of each player, the page will show a list of the Top 25/ Top 100. 

Buttons can be used to switch views to see all data values or simplified basic player attributes or to toggle between Top25/ Top 100

Runs local WebApp
